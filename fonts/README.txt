Self-hosted web fonts. Served from this domain on purpose: loading them from
fonts.gstatic.com would send every visitor's IP address to Google, which Dutch
and German data-protection rulings treat as a GDPR violation for an EU site.

Instrument Serif — Rodrigo Fuenzalida & Jordan Egstad, SIL Open Font License 1.1
  https://fonts.google.com/specimen/Instrument+Serif
Space Grotesk — Florian Karsten, SIL Open Font License 1.1
  https://fonts.google.com/specimen/Space+Grotesk

Files are the latin and latin-ext subsets Google Fonts serves (woff2).
Space Grotesk is the variable weight file (300–700).
